# Задачи Артёма · Backend и ML

## Показ из папки osminogi

Офлайн, с имитацией модели:

    ..\.venv\Scripts\python.exe -m backend.app.analysis.demo

С реальным CodexGenerator:

    ..\.venv\Scripts\python.exe -m backend.app.analysis.demo --live-model

Для второго запуска нужен уже запущенный CodexGenerator с RabbitMQ и его окружением. По умолчанию используется соседний проект AiStaff/CodexGenerator. Для другого расположения задайте GARDEN_CODEX_DIR. Настройки брокера берутся из окружения, пароль читает штатный клиент CodexGenerator. Для показа используйте выделенный брокер с одним потребителем очереди результатов.

## Что посмотреть

- findings: три учебные находки, секрет замаскирован.
- recommendations: source ai означает ответ модели или её имитации, rule — подсказку из правила.
- draft: расписание 14:00 и предупреждение про email. source model означает ответ модели или её имитации, fallback — резервный граф.
- comparison: число критических находок падает с 1 до 0. При возврате настройки ID сохраняется.
- scores: оценка на встроенном синтетическом наборе.

Ветки feat/01–08 содержат анализаторы, черновик, рекомендации и учебную правку. Ветка feat/09-codex-generator подключает существующий сервис. Рабочие ветки локальные. Перед будущими PR сверяем diff каждой ветки с общей main и прикладываем команду и её вывод. Прогон на эталоне организаторов и командный CI проверяются отдельно.


## Показ в браузере с Python-бэкендом

Из папки osminogi:

    ..\.venv\Scripts\python.exe -m backend.app.demo_server

Откройте http://127.0.0.1:8000. Сервер запускается на этой машине и использует встроенный синтетический проект.

1. Нажмите «Запустить проверку». На холсте выполнится ветка «Да». В результатах три находки.
2. Откройте критическую карточку и проверьте файл, строку и маску. В блоке Telegram доступен предпросмотр отчёта.
3. Нажмите «Применить учебное исправление», затем повторите запуск. Критический ключ будет в «Устранено», две другие находки останутся, выполнится ветка «Нет».
4. Подставьте пример в форму черновика, соберите граф, снизьте порог до «Высокая» и запустите. Ветка «Да» выполнится на исправленном снимке, итог останется зелёным.

Проверено в Chrome: оба прогона, маска в карточке, история, черновик и изменение ветки. Цикл в графе сервер отклоняет с 422. При недоступном CodexGenerator используются советы из правил и резервный черновик. Telegram работает в предпросмотре, серверное расписание и GitHub Actions в этой сборке не подключены.
