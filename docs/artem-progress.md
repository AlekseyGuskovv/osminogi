# Задачи Артёма · Backend и ML

## Быстрый показ

В каталоге репозитория выполните `python -m backend.app.analysis.demo`. Вывод JSON. В PyCharm можно запустить модуль `backend.app.analysis.demo` с рабочей папкой репозитория.

1. `findings` показывает три учебные находки, файл, строку и маску.
2. `scores` показывает верные находки, пропуски и ложные тревоги на синтетическом наборе.
3. `recommendations` и `offline_recommendations` показывают основной и резервный ответы.
4. `draft` содержит граф в 14:00 и предупреждение про email.
5. `patch` и `comparison` показывают правку, переход числа критических находок с 1 на 0 и возврат с прежним ID.

По умолчанию ответ модели имитируется. Для подключённой модели добавьте `--live-model` и выставьте `GARDEN_LLM_KIND` (`ollama` или `openai-compatible`), `GARDEN_LLM_URL` (полный путь к chat endpoint), `GARDEN_LLM_MODEL` и при необходимости `GARDEN_LLM_KEY`.
