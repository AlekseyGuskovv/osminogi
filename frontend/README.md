# Cyber Garden

React-редактор сценариев проверки Kotlin-проектов. Для запуска нужны Python-бэкенд и Node.js 22.12+ или 24.

## Запуск на Windows

Из корня репозитория в первом PowerShell запустите бэкенд. Если виртуальная среда находится в другой папке, подставьте путь к её Python.

```powershell
..\.venv\Scripts\python.exe -m backend.app.demo_server
```

Во втором PowerShell из корня репозитория запустите интерфейс.

```powershell
cd frontend
npm.cmd ci
npm.cmd run dev
```

Откройте `http://localhost:5173`. Vite передаёт API-запросы и события на `127.0.0.1:8000`. Если порт бэкенда отличается, перед запуском Vite задайте `$env:GARDEN_BACKEND_URL = "http://127.0.0.1:8007"`.

## Показать за две минуты

1. Нажмите **Режим демонстрации → Запустить учебную проверку → Запустить**. На исходном снимке появится критическая находка, граф пойдёт по ветке **Да**, CI будет заблокирован.
2. Выберите **После правок → Запустить**. CI пройдёт, граф пойдёт по ветке **Нет**. По ссылке **Открыть отчёт** доступны находки, сравнение и повтор на графе.
3. Для своего сценария нажмите **Проект организаторов** или **Загрузить ZIP**, добавьте нужные блоки и нажмите **Запустить**. Редактор сохранит изменения перед запуском.

Для генерации сценариев и нод нужен запущенный CodexGenerator. Если он лежит вне стандартного расположения, установите `GARDEN_CODEX_DIR` в первом терминале перед стартом бэкенда. Telegram выбирается в настройках соответствующего блока. YAML и Python-клиент CI скачиваются из меню **GitHub Actions** сохранённого сценария. Для этого экспорта нужен частный учебный репозиторий и настроенный self-hosted runner.
