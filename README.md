# Cyber Garden

Учебная платформа для защитной проверки Kotlin-проектов. Работа Артёма и команды описана в `docs/artem-progress.md`.

[Запуск интерфейса и демонстрация](frontend/README.md)

### Запуск защиты на Windows

Откройте папку [tools/defense](tools/defense). Чтобы подключить Telegram, скопируйте `Telegram.example.txt` в `Telegram.txt` и заполните `BOT_TOKEN` и `CHAT_ID`. Заполненный файл исключён из Git.

Дважды нажмите **Start Cyber Garden.cmd**. Скрипт соберёт интерфейс, запустит бэкенд и откроет редактор на `127.0.0.1:5188`. Для AI он попробует поднять подготовленный CodexGenerator из соседнего проекта и настроит локальную Ollama как резерв. Оставьте окно запуска открытым. На компьютере должны быть окружение Python проекта и Node.js или поддерживаемое окружение PyCharm.
