Подключение к GitHub Actions

В cyber-garden.yml уже записан ID сценария .

  1. В проверяемом приватном репозитории добавьте cyber-garden.yml в папку .github/workflows/.
  2. Скачайте Python-клиент и положите его в .github/scripts/. Отправьте оба файла в базовую ветку, например main.
  3. На компьютере с Octavius подключите к этому репозиторию Windows self-hosted runner с меткой cyber-garden. Git должен быть доступен ему в PATH.
  4. В GitHub откройте Settings → Secrets and variables → Actions → Variables. Задайте GARDEN_PYTHON с полным путём к python.exe на компьютере runner. Если порт Octavius отличается от 8000, задайте GARDEN_PORT. Для Kotlin-проекта в подпапке задайте GARDEN_PROJECT_DIR.
  5. Оставьте Octavius и runner запущенными и откройте PR между ветками этого репозитория. В сохранённом сценарии CI должны выполняться все три анализатора. Результат появится в разделе Checks этого PR.
